# STUDY OF CONDITIONAL STATEMENTS IN PYTHON

## AIM 
### To study and understand the concept of conditional statements in Python and to analyze how decision-making is implemented in programs using different types of conditional constructs.

## THEORY 
### Conditional statements are used in Python to control the flow of execution of a program based on certain conditions. They allow the program to make decisions and execute specific blocks of statements depending on whether a condition evaluates to True or False.
### In Python, indentation plays a crucial role in defining blocks of code. Unlike many other programming languages, Python does not use curly braces to define blocks. Proper indentation ensures the correct structure and readability of the program.

### A condition in Python always evaluates to a Boolean value, either True or False. Based on this result, the program decides which block of statements to execute.

### Types of Conditional Statements:

### if Statement
The if statement is the simplest form of decision-making statement. It executes a block of statements only when the specified condition is True. If the condition is False, the statements inside the block are skipped.

### if-else Statement
The if-else statement provides two alternative paths of execution. If the condition is True, one block of statements is executed; otherwise, another block is executed. This ensures that exactly one of the two blocks runs.

### if-elif-else Statement
This type of statement is used when multiple conditions need to be checked. The conditions are evaluated sequentially from top to bottom. As soon as one condition becomes True, its corresponding block is executed and the remaining conditions are skipped. If none of the conditions are True, the else block is executed.

### Nested if Statement
A nested if statement is an if statement placed inside another if statement. It is used when a secondary condition needs to be checked only after the first condition is satisfied. Nested structures help in solving complex decision-making problems.
